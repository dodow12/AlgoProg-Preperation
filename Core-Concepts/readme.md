# Algorithm and Programming Exercise Book

A progressive collection of C programming exercises designed to build
strong algorithmic thinking and prepare me for university-level
Computer Science.

The exercises increase in difficulty. An exercise is only considered
complete when I understand, test, and can modify my own solution.

---

## Completion Standard

Every exercise must satisfy these conditions:

- [ ] Requirements are fully implemented.
- [ ] Pseudocode is written before coding.
- [ ] The program compiles without warnings.
- [ ] Normal test cases pass.
- [ ] Edge cases are tested.
- [ ] Invalid input is handled when required.
- [ ] I can explain the algorithm without reading the code.
- [ ] I understand every important variable and operation.
- [ ] I can modify the program independently.
- [ ] The solution is my own work.
